
# Laptop Price Prediction Using Machine Learning

## Project Description
This project predicts laptop prices based on laptop specifications using Machine Learning and Streamlit.

## Features
- Laptop price prediction
- Multiple regression models
- Data preprocessing
- Dataset overview
- Interactive Streamlit frontend

## Machine Learning Algorithms
- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree Regression
- Random Forest Regression

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Project Files
- app.py - Streamlit application
- best_model.pkl - Trained machine learning model
- best_model_name.txt - Best model name
- model_features.json - Model input features
- laptops_cleaned.csv - Dataset
- requirements.txt - Required Python libraries

## How to Run

1. Clone this repository.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## Project Type
Machine Learning / Regression / Streamlit
